# 📖 ACTIVITY DETAILS

<details>
<summary><b>☕ ACTIVITY 1 — PRESENTATION DESIGN PRINCIPLES</b></summary>

<br>

### Overview

Activity 1 focused on the application of fundamental presentation design principles through the creation of a promotional flyer for a free coffee booth at Arrupe Hall, Booth 7.

The design aimed to communicate information quickly while maintaining a visually engaging composition.

### Design Principles Applied

- **Contrast** – making important text stand out.
- **Visual Hierarchy** – prioritizing the main message and supporting details.
- **Whitespace** – allowing the design to breathe.
- **Alignment** – maintaining organization and balance.
- **Imagery** – using visual elements to support the message.
- **Typography** – selecting appropriate fonts for readability.

### Learning Experience

This activity taught me that good design is more than decoration. It is about organizing information and guiding the viewer toward the most important message.

<img src="./IMAGES/activity-1.jpg" width="100%" alt="Activity 1"/>

</details>

<summary><b>🩺 ACTIVITY 3 — INFOGRAPHIC & PROJECT DOCUMENTATION</b></summary>

<br>

### Overview

Activity 3 explored the use of infographics to communicate information about long hospital waiting times.

The infographic, **Waiting for Care**, highlighted the problem of delays in healthcare services and the need for more efficient patient management.

### Proposed IT Solution: MediQueue

MediQueue is a proposed digital patient queuing and scheduling system designed to improve patient flow and support efficient hospital operations.

### Proposed Features

- Online booking and scheduling
- QR-code check-in
- Patient queue monitoring
- Real-time notifications
- Centralized dashboard
- Data analytics for patient flow

### Learning Experience

This activity allowed me to understand how technology can address real-world problems. It also helped me combine research, information organization, visual design, and project documentation.
