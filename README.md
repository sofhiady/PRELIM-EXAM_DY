## 🗂️ Activity Breakdown

<details open>
<summary><b>1️⃣ Presentation Design Principles</b></summary>
<br>

A promotional flyer for a free coffee booth event at Arrupe Hall, Booth 7. Key principles applied: contrast, visual hierarchy, whitespace & grid alignment, imagery as focal point, and supporting line-art.

<p align="center">
  <img src="sofhia-images/coffee-flyer.jpg" width="360" alt="Coffee booth flyer"/>
</p>

> 💭 *"Good design doesn't shout — it just makes sure you notice the right thing first."*

</details>

<details open>
<summary><b>2️⃣ Color Palette & Typography</b></summary>
<br>

A personal brand identity built around the initials "SD," using a blue/off-white palette and a Montserrat + Fira Code type pairing, applied consistently across every asset. *(See the full brand sheet above in the Brand Kit section.)*

</details>

<details open>
<summary><b>3️⃣ Infographic & Mini Project Documentation</b></summary>
<br>

**Infographic:** *Waiting for Care* — visualizes an average 139.97-minute outpatient wait time, its causes, and a proposed fix.
